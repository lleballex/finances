# План разработки

Спецификации остаются источником требований. План фиксирует очередность работ и ограничения реализации.

1. **Начальная итерация:** разделить существующие компоненты UI-kit на читаемые модули, сохранить их демонстрацию и создать публичную страницу по макету. Авторизация недоступна до реализации backend.
2. **Завершено:** оболочка рабочего пространства и навигация в предпросмотре `/preview`. Защищённые маршруты и пользовательское меню зависят от авторизации.
3. Авторизация: реализованы backend, пользователь и вход через Яндекс ID; полная проверка входа ожидает настройки Redirect URI в Яндекс OAuth.
4. Категории: модель, API и управление категориями.
5. Транзакции: реализованы таблицы, чтение данных пользователя с фильтрами и постраничной загрузкой и интерфейс списка. Требуются управление категориями, создание, редактирование и удаление транзакций.
6. Дашборд и статистика на реальных данных.

Неопределённые в спецификациях решения, в том числе расчёт темпа трат и окончательная графика стартовой страницы, требуют отдельного согласования до реализации соответствующего поведения.
